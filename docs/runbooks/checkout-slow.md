# CheckoutSlow

p95 `GET /work` за 1 минуту выше 300 мс и держится 30 секунд.

Правило только поднимает тревогу. Healer сам смотрит p95 и throttle по подам. Один под хуже остальных — удаляет его. Все упёрлись в CPU — поднимает реплики до 5. Когда алерт гаснет и поды снова быстрые, возвращает 2 реплики.

Ручная имитация задержки релиза: env `EXTRA_LATENCY_MS` на Deployment `checkout`, значение в миллисекундах. Это поле шаблона пода, не ConfigMap. После проверки вернуть `0`.
