# Сверка с ТЗ кейса 2

Источник: `Конкурс_кейсов_devops_командный_2_1.docx` из сохраненного Telegram-экспорта. Текст повторно прочитан полностью 7 октября 2026 по московскому времени. Кейс 1 рассматривается как отдельное задание; его обязательные пункты не объявляются требованиями кейса 2. Формулировка «105%» используется как требование полноты проверки, а не как измеренный процент выполнения.

Полный стек через Ansible: `cd ansible && ansible-playbook -i localhost, playbooks/stack.yaml -e sre_cluster=mtc`. Docker, make, kubectl, Helm и k3d должны быть установлены по README. Роль node-logs использует sudo для системных служб. Обычный одношаговый вход `make up-linux` также сохранен.

Дополнительные AIOps auto-fix, eBPF и функции кейса 1 не добавляются ради формального процента. Для подачи важны проверенные требования кейса 2, достоверные результаты и явные ограничения.
