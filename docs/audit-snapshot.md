# Аудит согласованности снимка метрик

При реальном отказе Redis наблюдалось `redis_error_ratio=1.0000000000000002`. Запросы разных счетчиков выполнялись на разное время; при непрерывном поступлении запросов числитель и знаменатель расходились. Начальная диагностика также попадала в окно прогрева свежих серий и безопасно запрещала действие.

Сбор привязан к одному `time` Prometheus. Допускается только погрешность округления до `1e-9` на границах доли; существенное расхождение и отсутствующие серии запрещают действие. Проверка долей зависимостей в диагностике больше не заменяет отсутствующие данные нулем. Отдельные тесты проверяют единое время всех запросов и различие округления от неверного счетчика.
