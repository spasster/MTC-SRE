# Видео демонстрации

[Открыть видео, 4 минуты 33 секунды](demo.mp4). Запись выполнена 7 октября 2026 по московскому времени на отдельном k3d mtc-review. Настоящие кадры браузера сохранены с интервалами настенных часов, эксперимент не ускорен монтажом. Русское пояснение озвучено Microsoft Irina, голос не принадлежит участнику команды. [Метаданные записи](results/iteration-1/demo-video.json).

На первом кадре здоровые запросы и две готовые реплики. Заранее заданные пять дополнительных запросов/с добавлены поверх трех фоновых: суммарно около 8 RPS. Healer применяет dry-run и scale до пяти, затем проверяет свежую синтетику, минутное окно и готовность Deployment. Внешний MTTR до трех здоровых измерений - 198.1 с. k6 завершился по заданной длительности 210 с; healer самостоятельно вернул две готовые реплики через 228.5 с после инъекции. Скрипт увидел этот результат до завершающей очистки. [Исходный эксперимент](results/iteration-1/demo-lifecycle.json).

| Время видео | Подтвержденное событие |
|---|---|
| 0:00 | Здоровое исходное состояние |
| 0:10 | Внесение дополнительной нагрузки |
| 1:33 | Принятие масштабирования Kubernetes API |
| 3:15 | Внутреннее подтверждение здоровья healer |
| 3:28 | Три последовательных здоровых измерения внешнего скрипта |
| 3:58 | Естественное завершение k6 и наблюдение двух готовых реплик после возврата healer |
| 4:33 | Здоровый завершающий кадр |

1051 дополнительный запрос получил HTTP 200; dropped iterations нет. Клиентский p95 за весь прогон - 354.3 мс: он включает период нарушения SLO и не заменяется здоровым минутным окном в конце. Видео доказывает восстановление, а не непрерывное соблюдение SLO.

Журнал healer в этой серии начал инцидент до новой инъекции; его MTTR 249.2 с объединяет соседние попытки и не является MTTR отдельного видео. Внешний отсчет 198.1 с начинается от текущей инъекции. Разница зафиксирована для исправления изоляции экспериментов в следующем аудите; внутреннее число не подменяет внешний результат.

Первый профиль 6 RPS не успел подтвердить полный цикл в короткой записи; прогон остановлен и [сохранен отдельно](results/iteration-1/demo-lifecycle-initial.json). Старое видео с ручной завершающей очисткой заменено. Секреты и личные чаты в кадры не попадают.

Для повторения подготовить port-forward Prometheus на 19090 и выполнить в корне:

```sh
python scripts/demo-server.py --cluster mtc
python scripts/experiment.py --cluster mtc --scenario spike --mode auto --natural-end --spike-rate 5 --spike-duration 210 --timeout 330 --output .runtime/demo-result.json
```

Открыть http://127.0.0.1:18765. Сервер слушает только localhost и показывает реальные данные. Перед инъекцией дождаться здорового SLO и погашенных алертов. Генерацию LLM и другие нагрузочные задания выполнять после записи. Для сравнения между запусками сохранять профиль, параметры среды и неудачные результаты.
